## **`Objetivo`**

el proposito de este proyecto es diseño y construir una maceta inteligente capaz de cuidar una planta de forma automatica. El sistema utiliza sensores para medir la humedad del suelo la luz y la temperatura y con esa info activa distintos actuadres coomo una bomba de agua luces leds etc de esta forma la maceta mantiene las condiciones adecuadas para el crecimiento de la planta sin necesidad de intervencionn constante del usuario

## **`Descripción del Proyecto`**
El proyecto consiste en crear una maceta inteligente que pueda monitorear y mantener las condiciones ideales para una planta de forma automática Para lograrlo se utilizan sensores que miden variables del entorno como la humedad del suelo la luz y la temperatura Estos datos son procesados por un microcontrolador como un Arduino o ESP32 que decide cuándo activar distintos actuadore por ejemplo
una bomba de agua para regar un humidificador ultrasónico para mantener la humedad ambiental y luces LED para dar iluminación cuando falta sol Lo que se busca lograr es un sistema capaz de cuidar una planta de manera autónoma reduciendo la necesidad de intervención humana y asegurando que la planta crezca en condiciones óptimas Además el proyecto busca aplicar conocimientos de electrónica sensores y programación en una aplicación práctica y ecológica
